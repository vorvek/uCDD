# uCDD (Micro CD Drive)

uCDD is a DOS virtual CD drive project for MS-DOS and FreeDOS. It aims to mount ISO, CUE/BIN, and other common disc image formats as virtual drives, including emulation of Red Book CD-Audio.

CD-Audio emulation is the project's intended distinction from SHSUCDHD/SHSUCDX, allowing software to access both data and audio tracks from disc images.

## Status

Initial project setup. No driver, executable, or image format support is implemented yet.

## Planned scope

- Run under MS-DOS and FreeDOS.
- Mount ISO and CUE/BIN images, with additional common formats to follow.
- Expose disc images as virtual CD drives to DOS software.
- Emulate Red Book CD-Audio, including mixed-mode discs with data and audio tracks.

The implementation, build toolchain, hardware requirements, and audio output methods are still to be defined.
